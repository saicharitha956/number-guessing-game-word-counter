# Number Guessing Game & Word Counter

## About the Project
A Python project that includes a number guessing game and a text file word counter.

## Features
- Generates random numbers between 1 and 100
- Provides hints: Too high or Too low
- Tracks attempts, score, and best score
- Allows replaying the game
- Reads text files and counts words
- Displays total words, unique words, and the top 10 frequent words
- Handles invalid guesses and missing files

## Technologies Used
- Python 3
- Random module
- Collections Counter
- File handling
- Loops and functions

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run the command:

```bash
py main.py
```

Keep `sample.txt` in the project folder to use the Word Counter.

## Scoring Rule
The player starts with 100 points and loses 10 points for each incorrect valid guess. The score cannot go below zero.
